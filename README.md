# ならぶ

ラーメン屋の行列に8000人並ぶiOSアプリです。

## コンセプト

並んでいる先は「世界一号店」というただのラーメン屋です。
それなのに列が長すぎて、住宅街から森、海、雪国、砂漠を抜け、宇宙に出て、
地獄と天国を通ってようやく店にたどり着きます。**前提が地味なほど、道のりの狂いかたが可笑しくなる**、
というのがこのアプリの笑いどころです。

「意味はないけど、あと100人だけ進めたくなる」体験を目的にしています。
数字を見るアプリではなく、**本当に8000人並んでいる世界**を作ることを最優先しています。

## 仕組み

- **列**: 手前に後ろの人、中ほどに自分、その先に前の人が並び、奥は地平線まで人で埋まっています
  （`QueueWorldView`）。遠近法で奥ほど小さく、景色に溶けて薄くなります。
- **人**: 種族・年齢・服装・持ち物・行動を並び順から生成します（`PersonFactory`）。
  スマホを見ている高校生、立ったまま寝ているサラリーマンに混じって、武士、宇宙人、着ぐるみ、
  サンタ、メイド、相撲取り、亡霊、天使が並んでいます。**その人が立っている場所によって顔ぶれが変わり**、
  宇宙では宇宙人が、天国では天使が増えます。進んでも同じ人は同じ姿のままです。
- **前の人の一言**: すぐ前の人が吹き出しでぽつりと漏らします。「昨日から並んでます」「私、実は偽物です」
  「この列、地球3周してるそうです」など。本当かどうかは分かりません。列が進むたびに話し相手が変わります。
- **景色**: 1000人進むごとに住宅街 → 商店街 → 森 → 海 → 雪国 → 砂漠 → 宇宙 → 地獄 → 天国 → ラーメン屋と
  移り変わります（`QueueWorld` / `SceneryRenderer`）。路面の目地と両脇のものが手前に流れて歩いている感じを出し、
  場所の境目では前の景色を薄く重ねて繋いでいます。宇宙では星が瞬き、地獄では火の粉が舞います。
- **アクション**: 前の人に対して肩を叩く・話しかける・驚かせる・応援する・ハイタッチができます。
  反応はランダムで、絡みすぎると相手にされなくなります。2%の確率で相手が列を抜け、1人ぶん進みます。
- **ガチャ**: 初回だけスタートダッシュ5連が無料で引け、以降は1時間ごとに1回無料です。
  出るのは列をごぼう抜きできる乗り物で、ダッシュ5人（N・35%）、自転車20人（R・30%）、
  バイク50人（SR・20%）、車100人（SSR・12%）、電車300人（UR・3%）。
  排出率・人数・演出時間はすべて `GachaCatalog` に集約してあり、UI側には数値を書いていません。
  残り時間は画面上のカウントではなく、保存した最終ガチャ時刻と現在時刻の差から求めるので、
  アプリを閉じている間も進みます。
- **ごぼう抜き**: アイテムを使うと列から横に出て乗り物に乗り、列の横を高速で進みます。
  周りの人が後方へ流れ、「20人抜き！」のカウンターが増えていき、終わると列に戻ります。
  順位は先に確定させ、画面だけが演出の時間をかけて追いつく作りなので、
  途中でアプリを閉じてもアイテムが消えたままにはなりません。演出中は操作を受け付けません。
- **列の進行**: 進捗は保存せず、基準時刻からの経過時間だけで毎回計算します（`QueueEngine`）。
  昼はおよそ4秒に1人、深夜でも10秒に1人は進み、受付までは半日ほどかかります。
  同じ入力には必ず同じ結果を返すため、未来の位置を先読みして通知を予約できます。
- **割り込み**: ときどき、課金して割り込んでくる人がいます。順番が戻り、通知が届きます。
- **景品**: 受付で受け取った景品は通し番号入りの整理券とともに図鑑に記録されます。
  周回ごとに受け取る品は決まっており、引き直しはできません。

## 収益化

消耗型App内課金で「100人抜かす」を販売します（Product ID: `io.github.supamucho76wq.narabu.skip100`）。
意味のない行列を、お金を払って進むという設計そのものがネタです。開発ビルドでは課金なしで動作します。

## 開発環境

- Xcode 26以降 / Swift 6 / iOS 17以降
- SwiftUI（Canvas） / StoreKit 2 / UserNotifications

このリポジトリはWindows上で生成しているため、最終ビルドと実機テストはmacOS上のXcodeで行います。

## Macでの開始手順

1. XcodeGenをインストールします。
2. このディレクトリで `xcodegen generate` を実行します。
3. `Narabu.xcodeproj` をXcodeで開きます。
4. Signing & CapabilitiesでTeamとBundle Identifierを設定します。
5. 実機を選択してビルドします。

## Codemagicでの配信

`codemagic.yaml` の `ios-testflight` ワークフローでTestFlightまで配信します。
署名にはCodemagicの環境変数グループ `code-signing` の `CERTIFICATE_PRIVATE_KEY` を使います。
